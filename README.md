Netflix Movies Analysis
This Excel dashboard analyzes 50 Netflix movies using: 
- IMDb Rating distribution 
- Genre popularity vs IMDb rating 
- Release year trend 
- Age rating breakdown 
- Top 5 movies 
- Duration analysis 
- Dynamic slicers and insights panel 

Tools Used: 
- Excel Pivot Tables 
- Slicers 
- Conditional Formatting 
- Column, Bar, Line Charts 
- Custom Colors (Netflix theme)
